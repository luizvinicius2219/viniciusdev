## Aplicar no repositorio local

Extraia os arquivos sobre `C:\viniciusdev`, depois execute:

```powershell
cd C:\viniciusdev
npm install
npm run dev
```

Depois de validar:

```powershell
git add .
git commit -m "feat: personalize portfolio with blue identity and personal media"
git push
```
